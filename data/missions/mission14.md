# Mission 14 — Byproduct Reduction Design

## Theme
Flux diagnostics and metabolic engineering evidence.

## Learning goal
Understand that a metabolic design should not only increase a target product. It should also monitor and reduce unwanted byproducts that compete for carbon and flux.

## Scenario
Dr. Almeida wants to improve the previous succinate-production analysis. The target product is still succinate, but the strain should now reduce an unwanted byproduct while keeping the setup supported by production-flux evidence.

## Mission description
Build on the previous pFBA analysis for succinate production.

Use exactly one useful knockout from the candidate list:

- b0903
- b2297
- b0728
- b3115
- b0118
- b1241

Track both the target product and the unwanted byproduct using Production Flux evidence.

## Briefing
In metabolic engineering, a good strain design is not judged only by the target product flux. Side-products can waste carbon, reduce yield, or indicate that the flux distribution is not yet well controlled.

A knockout can redirect metabolism by blocking a route that contributes to an unwanted product. The challenge is to reduce that byproduct without losing the target product.

Use simulation evidence to compare the target product with the unwanted byproduct and decide whether the design is ready.
