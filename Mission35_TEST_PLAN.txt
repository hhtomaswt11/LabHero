MISSION 35 — MANUAL VALIDATION PLAN
===================================

Use the project environment with pygame/mewpy installed.

0. Regression commands
----------------------
From the project root:

python3 -m compileall code backend/app tests main.py LabHero.py
python3 tests/test_mission35.py
python3 -m unittest discover -s tests -p "test_*.py"

1. Final NPC / activation
-------------------------
A. Before Mission 34 is complete, approach the Tiled NPC named Final and press ENTER.
   Expected: Dr. Richter (richter.jpg) says the final qualification is locked; no mission button opens.

B. Complete Mission 34, approach Final, press ENTER.
   Expected: the Mission 35 introduction appears and Yes opens the Mission 35 menu.

C. Activate Mission 35.
   Expected:
   - Mission 35 is added to activated missions.
   - Its report starts empty.
   - Genes b0114, b0726 and b0116 are highlighted in the simulator gene menu.
   - Golden LabHero is NOT yet visible/selectable in the C skin menu.

5. Invalid-attempt preservation
-------------------------------
After the dossier is complete, run one invalid setup, for example:
- FBA instead of pFBA, OR
- close the O2 lower bound in a normal design run, OR
- add an unrelated knockout, OR
- use an incomplete/wrong Production Flux panel in a design run.

Expected:
- Latest attempt was not recorded.
- Previously valid Mission 35 dossier evidence remains available.
- Design remains 4/4, curves remain 2/2, objective audit remains 1/1.

6. Repetition / no duplication
------------------------------
Repeat a previously valid design condition and one complete oxygen curve.
Expected counts remain 4/4 and 2/2. Existing slots are replaced, not appended.

7. Final answers
----------------
First try deliberately wrong values, e.g.:
- target: b0114
- bound: -10
- viability: yes
Expected: mission does not complete and feedback identifies the first incorrect conclusion.

Then submit the three conclusions supported by the completed dossier.
Expected:
- Congratulations / E. coli certification complete message.
- Mission 35 enters missions_completed once.
- No duplicate reward if delivery is attempted again.

8. Golden skin reward
---------------------
Before Mission 35 completion:
- press C and verify Golden LabHero is not shown/selectable.

After Mission 35 completion:
- close the mission menu;
- press C;
- verify Golden LabHero appears;
- select it with Enter;
- move in all directions and verify idle/walk animations.

Expected: skin is unlocked but not auto-equipped.

9. Persistence
--------------
After completion and (optionally) equipping Golden LabHero:
- close the game fully;
- restart and load the same save.
Expected:
- Mission 35 is still complete;
- Dr. Richter gives the completed dialogue;
- Golden LabHero remains unlocked;
- if it was equipped, the selected skin remains equipped;
- logical progression helpers derive Golden Lab / yeast programme access from Mission 35 completion.
